# 営業支援用LP型アプリ｜体験デモ

Sophia Laboが制作する「LP型アプリ」の体験用デモです。

このデモでは、オンラインスクールへの参加を検討している見込み客役として質問に答えながら、

- 自分が何に悩んでいるのか
- 何を知りたいのか
- どんな未来を望んでいるのか
- 次に何をしたいのか

を整理していく体験ができます。

## LP型アプリとは

LP型アプリは、商品やサービスを一方的に説明するためのものではありません。

閲覧者が質問や選択を通して、

**「自分の場合はどうなのか」**

を考えながら、自分の現在地や判断材料を整理していくためのWeb体験です。

一般的なLPが「理解・信頼をつくる」役割を担うとすれば、
LP型アプリはその後の

**自分に当てはめる → 整理する → 次の行動を自分で選ぶ**

という部分を支援します。

## このデモで体験できること

この試作品では、大きく2つの視点を体験できます。

### 1. 見込み客として体験する

オンラインスクールを検討している見込み客役になり、
いくつかの質問や選択をしながら、自分の悩みや希望を整理します。

特定の商品や講座を自動でおすすめすることが目的ではありません。

相談する場合も、今は相談しない場合も含めて、
最後の行動は利用者自身が選びます。

### 2. 提供者として振り返る

見込み客としての体験後、

「自分は何をしていたのか？」

を振り返ります。

LP型アプリが目指しているのは、
営業側が欲しい情報を集めるだけの質問フォームではなく、
見込み客自身にも「整理」「気づき」「判断材料」を返す体験です。

## 大切にしている考え方

この試作品では「売らない営業」という考え方を大切にしています。

無理に相談へ誘導したり、
不安や恐怖を強めて契約を迫ったりするのではなく、

見込み客自身が自分にとって必要な未来を考え、
納得して次の行動を選べる状態をつくる。

そのための「相談前の体験」を、
LP型アプリでどこまでつくれるのかを検証しています。

そのため、

**「相談しない」「今はやめておく」と自分で判断できたことも、
一つの成功だと考えています。**

## このデモの位置づけ

このアプリは、LP型アプリの考え方や体験を伝えるための試作品です。

特定のオンラインスクールの商品・講座を販売するものではありません。

また、診断結果によって商品を自動提案したり、
利用者の代わりに意思決定したりすることを目的としていません。

実際に導入する場合は、商品・サービス、顧客の悩み、営業プロセスなどに合わせて、質問・分岐・表示内容・CTAを個別に設計します。

## 想定している活用例

LP型アプリは、たとえば次のような場面での活用を想定しています。

- 高単価サービスの相談前整理
- オンラインスクール・講座の相談前体験
- 複数プランから選ぶ前の判断材料整理
- 初回ヒアリング前の課題整理
- LPを読んだ後の「自分の場合」の整理
- 営業・相談前の認識合わせ

すべてのサービスにLP型アプリが必要だとは考えていません。

商品がシンプルで、利用者がすでに購入するものを決めている場合などは、
通常のLPや申込みフォームだけで十分なケースもあります。

## 技術構成

この試作品は、シンプルなWebアプリとして制作しています。

- HTML
- CSS
- JavaScript

ログイン、決済、AI API、高度なデータ保存などは使用していません。

回答内容はブラウザ上で一時的に扱われ、外部への自動送信やブラウザへの永続保存は行いません。

相談を希望した場合のみ、利用者自身の操作で外部のGoogleフォームへ移動します。
